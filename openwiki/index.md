# Omnisight Platform - Engineering Wiki

Welcome to the comprehensive engineering documentation of the **Omnisight Platform**. This wiki demonstrates expertise in system architecture planning, API design management, quality engineering, database software engineering, AI and algorithm design, software engineering system development, system integration analysis, and system maintenance operations.

- **[Architecture Deep Dive](architecture-deep-dive.md)** - System architecture planning, modular monolith design, and integration analysis.
- **[API Design & Management](api-design-principles.md)** - RESTful API design, versioning strategy, authentication patterns, and API quality assurance.
- **[AI & RAG Orchestration](ai-rag-orchestration.md)** - Retrieval-Augmented Generation pipeline, vector search algorithms, and LLM integration architecture.
- **[Data & Database Design](data-system-design.md)** - PostgreSQL schema, query optimization, vector database architecture, and migration strategy.
- **[Quality Engineering & QA](quality-engineering-qa.md)** - Multi-layer testing strategy, CI/CD quality gates, and software quality assurance practices.
- **[DevOps & Deployment](devops-deployment.md)** - Containerization, Kubernetes deployment, infrastructure as code, and monitoring stack.
